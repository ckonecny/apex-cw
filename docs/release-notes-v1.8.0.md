# APEX CW v1.8.0

Listen and Send now work the same way, an external CW key is recognised
everywhere, and the statistics show which characters you mix up. This also
contains everything from the 1.7.1 maintenance round (firmware audit).

## New
- **External key (USB CW adapter):** a straight-key symbol in the app bar of
  almost every screen shows whether the adapter is recognised and opens its
  settings. Dit/dah sound on screens without their own keying (also on the home
  screen). With a key detected, the touch keys can be hidden. On the Send
  result page dah = next block, dit = finish. Settings show the adapter's name
  and USB id, active or inactive.
- **Mix-ups:** Listen (typing mode) records which characters you confuse, per
  day; the character statistics get a "Trends" tab and a mix-up curve. A card
  "Recurring mix-ups: practice these?" boosts both characters of a pair.
- **Send looks and draws like Listen:** weak characters, mix-up pairs and the
  "On the way to" bar on the start view; same running view and result page;
  Koch random characters are drawn by the same rule as in Listen.
- **Compact start views:** with little room (large font, small display) one
  "Practice focus" row replaces the cards; tapping opens a sheet.
- **Koch sequences with the prosign tail:** M32, LCWO, CW Academy and LICW now
  include the six prosigns SK, AS, KN, KA, VE and BK as lessons (51 steps), as on
  the Morserino. They sound as one prosign, also in tap playback.
- **Morse tree with the external key:** walk the tree yourself, dit to the left,
  dah to the right; a pause ends the walk.
- **Random groups from length 1** to drill single characters.
- **Character chart** now also lists Ä Ö Ü CH.
- **Navy & orange theme:** all menu icons orange.

## Changed
- **Settings** reorganised: USB CW adapter below Keyer; call signs now live in
  the Listen/Send ⚙ sheets; Send's "answer pause" replaces word spacing.
- **Listen and Send:** one shared tempo + spacing block; Send has Stop in the
  app bar and the paddles at the bottom while a block runs.
- **Spaced daily goal:** each session credits at most goal ÷ number of sessions.
- Weak-character card only for random character groups; the Words chip says
  "none fit" instead of "ca. 0".

## Fixed (from 1.7.1)
- **Letter and word gaps were one dit too short** in all earlier versions: now
  exactly 3 and 7 dits at the default spacing, so everything sounds slightly slower.
- Keyer modes follow the firmware (Iambic A/B, Ultimatic, Non-Squeeze); Mixed
  and Boost weighting; Echo start deadline.
- Audio: no crashes or stuck tones when the output route changes; microphone
  decoder no longer busy-loops.
- Learned dah key is stored correctly; the weak-character card refreshes when
  the engine mode changes.

## Updated libraries
`audio_session` 0.2.4, `shared_preferences`, `url_launcher`, `cupertino_icons` 2.0.0, Gradle 9.8.1, Android Gradle Plugin 9.4.1, Kotlin 2.4.21.
