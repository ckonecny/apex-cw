# APEX CW v1.7.1

Maintenance release: every native module (keyer, generator, echo evaluation,
tone engine, microphone decoder) was checked line by line against the
Morserino-32 firmware V9.0.

## Fixed
- **Letter and word gaps were one dit too short in all earlier versions.**
  They are now exactly 3 and 7 dits at the default spacing, so everything
  sounds slightly slower than before (Listen, Send prompts, WiFi Trx playback).
- **Keyer modes** follow the firmware: Iambic A forgets short opposite taps
  during an element, Ultimatic and Non-Squeeze were corrected, the CurtisB
  slider only shows for Iambic B. Fixed a race when starting/stopping the keyer.
- **Mixed** mode and **Boost** weighting follow the firmware; the abbreviation
  list now includes "Z".
- **Echo trainer:** the start deadline uses the firmware's effective word space.
- **Audio:** no more crashes or stuck tones when the output route changes
  (e.g. Bluetooth disconnects while playing).
- **Microphone decoder:** no busy loop on read errors, stale recorders are
  released.

## Under the hood
- Kotlin unit tests and a host C++ test (ASan/UBSan) now run in CI.
- Automated security scanning (CodeQL, OSV, Dependabot).
