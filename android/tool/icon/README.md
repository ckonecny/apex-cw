# App icon

`icon_source.jpg` — the app icon as designed by Sia, OE1LMR (finished rounded-square
image). `make_icon.py` builds the Android launcher icons from it into
`android/app/src/main/res/mipmap-*` (adaptive foreground + legacy icon);
`icon_fullbleed.png` / `icon_rounded.png` are its 1024 px previews. See
`docs/DECISIONS.md` ("App icon").
